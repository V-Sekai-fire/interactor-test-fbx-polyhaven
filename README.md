# interactor-test-fbx-polyhaven

Public-domain test models in FBX and OBJ form, each with a record of its title, author, source and licence, for importer tests.

## What it is for

Each model comes as an FBX file and as a gzipped OBJ with its material file, beside a JSON record of where it came from.

## Licence

Each model is CC0 1.0, as its JSON record states.
